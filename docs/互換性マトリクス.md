# クライアント互換性マトリクス

要件書 FR-015 の記録。**実際に接続して確認できたことだけ**を書く。

## 「対応済み」の定義

以下をすべて通過したクライアントにだけ「対応済み」を付ける。1つでも未確認なら「接続確認のみ」。

1. 認証（正しいトークンで通る／誤ったトークンで 401）
2. ツール一覧の取得（5ツールが見える）
3. 検索が出典つきで返る
4. エラー時の挙動（存在しない chunk_id 等）
5. 長文の応答（大きい Pack のエクスポート）
6. タイムアウト
7. 再接続

クライアントやプロトコルの変更で壊れた場合、状態を「要再検証」へ戻す。
